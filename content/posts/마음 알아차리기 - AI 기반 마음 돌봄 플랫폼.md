# **AI가 분석해주는 개인 맞춤형 마음 돌봄 및 자기 성찰 플랫폼**

## 📋 목차

- 앱 개요
- 핵심 기능
- 사용자 경험 흐름
- 기술적 특징
- 사용 방법
- 개발 배경

## 앱 개요

마음 알아차리기는 일상 속 생각과 감정을 AI가 분석하여 개인화된 마음 돌봄 조언을 제공하는 웹 애플리케이션입니다. 단순한 챗봇이 아닌, 사용자의 과거 대화 맥락과 감정 패턴을 학습하여 점점 더 정확하고 개인화된 분석을 제공합니다.

### 🎯 주요 목표

- **자기 이해 증진**: 내 생각과 감정 패턴을 객관적으로 바라보기
- **감정적 안정성**: AI 기반 맞춤형 조언으로 마음의 평온 찾기
- **지속적 성장**: 대화가 쌓일수록 더욱 정확해지는 개인화 분석

## 핵심 기능

### 1. 🤖 AI 기반 맥락 인식 분석

**특징:**

- Google Gemini 2.5 Flash Thinking 모델 사용
- 과거 대화 내역을 바탕으로 개인화된 분석 제공
- 감정 상태, 사고 패턴, 가치관 자동 추출

**분석 요소:**

- **감정 상태**: 기쁨, 슬픔, 불안, 화남, 답답함, 부담감 등 세분화된 감정 인식
- **사고 패턴**: 반추, 완벽주의, 자기비판, 걱정, 이분법적 사고 등 15가지 패턴 분석

### 2. 💭 3단계 피드백 시스템

#### 📍 1단계: 공감적 피드백

- 사용자의 감정을 깊이 이해하고 공감하는 메시지
- 현재 상황의 어려움을 인정하고 격려

#### 📍 2단계: 객관적 관점

- 한 걸음 물러서서 상황을 다각도로 바라보기
- 생각과 현실을 구분하여 새로운 시각 제공

#### 📍 3단계: 마음 돌봄 연습

- 개인 맞춤형 실습 가이드 제공
- 6가지 핵심 연습: 자기자비, 관찰자 자기, 마음챙김, 수용, 기꺼이 경험하기, 가치 명료화

### 3. 🔄 통합 인사이트 생성

**맞춤 분석:**

- 현재 고민과 과거 대화 맥락을 연결한 종합적 분석
- 반복되는 심리적 패턴 인식
- 단기/중기/장기 실천 계획 제안

### 4. 🎧 인사이트 청취 시스템

**플레이리스트 기능:**

- AI가 분석한 통합 인사이트를 플레이리스트로 저장
- TTS(Text-to-Speech)를 통한 음성 재생
- 통근길이나 휴식 시간에 편리하게 복습 가능

**관리 기능:**

- 플레이리스트 생성, 편집, 삭제
- 인사이트 순서 조정
- 재생 제어 (재생, 일시정지, 이전/다음)

### 5. 📊 마음 분석 대시보드

**통계 및 시각화:**

- 감정 상태 변화 추이 그래프
- 사고 패턴 분석 차트
- 가치관 우선순위 변화 (구현 예정)
- 월별/주별 마음 건강 지수 (구현 예정)

**패턴 인식:**

- 메타인지, 대처 능력, 사고 유연성 자동 계산 및 수치화 (분석의 민감도가 낮아 현재 수정 중)
- 개선 추천사항 제공 (수정 중)

### 6. 🔒 프라이버시 및 보안

**데이터 보호:**

- Supabase 기반 안전한 클라우드 저장
- Row Level Security (RLS) 정책 적용
- 개인정보 암호화 저장

**익명성 보장:**

- 개인 식별 정보 수집 최소화
- 데이터 익명화 처리
- 사용자 동의 기반 데이터 활용

## 사용자 경험 흐름

### 📱 초기 설정

1. **간편 가입**: 이메일만으로 즉시 시작
2. **첫 대화**: 현재 마음 상태나 고민 입력
3. **AI 분석**: 감정, 사고 패턴 자동 분석

### 🔄 일상 사용

4. **생각 입력**: 자유로운 형식으로 현재 감정이나 고민 작성
5. **AI 분석 받기**: 3단계 피드백(공감, 객관화, 통합 인사이트)과 맞춤형 마음 돌봄 연습 제공
6. **인사이트 저장**: 중요한 분석 결과를 플레이리스트에 추가
7. **통계 확인**: 마음 분석 페이지에서 변화 추이 확인

### 📈 장기적 성장

- **패턴 인식**: 반복되는 심리적 패턴을 스스로 알아차리기
- **대처 능력 향상**: 다양한 마음 돌봄 기법 습득
- **자기 이해 심화**: 자신만의 감정 처리 방식 발견

## 기술적 특징

### 🛠 기술 스택

- **Frontend**: Next.js 15, TypeScript, Tailwind CSS
- **AI Engine**: Google Gemini 2.5 Flash Thinking
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **UI Components**: Radix UI, Shadcn/ui

### 🧠 AI 알고리즘

- **하이브리드 샘플링**: 시간 분산 + 품질 분석으로 최적의 맥락 메시지 선별
- **적응형 메타인지 분석**: 자기 인식, 대처 스타일, 인지적 유연성 측정 (구현 중)
- **맥락 인식 학습**: 대화가 누적될수록 더욱 정확한 개인화 분석

### 📱 사용자 경험 (UX)

- **반응형 디자인**: 모바일, 태블릿, 데스크톱 최적화
- **다크 모드**: 눈의 피로를 줄이는 어두운 테마 지원
- **접근성**: 스크린 리더, 키보드 내비게이션 지원
- **PWA 지원**: 모바일에서 앱처럼 설치 가능

- **인사이트 활용**: 좋은 조언은 플레이리스트에 저장해서 반복 청취

### 3. 주요 기능 활용

- **🏠 홈**: 새로운 생각 분석 받기
- **📊 마음 분석**: 감정 변화 추이 및 패턴 확인
- **🎧 인사이트 청취**: 저장된 인사이트를 음성으로 복습(한글 및 영어 음성 지원)
- **📱 앱 소개**: 상세한 기능 설명 및 FAQ

- **수용전념치료**: 현재 순간에 집중하며 판단 없이 자신의 생각과 감정을 관찰하는 연습

3. **지속가능한 돌봄**: 일회성이 아닌 장기적 마음 건강 관리

## ❗ 한계점 및 보완 필요 요소

### 1. ⏳ 분석 시간 지연 (가장 큰 이슈)

- 메시지 분석에 평균 1분 이상 소요, 사용자 입장에서 체감되는 대기 시간이 길어 몰입도 저하
- 실시간 반응이 중요한 심리 지원 서비스 특성상, 빠른 응답 속도 확보가 시급

### 2. 🧠 AI 처리 용량 이슈

- 복잡한 메시지 분석 시 처리량 증가로 인해 오류 발생 가능성 있음

### 3. 🌐 불안정한 네트워크 환경

- 네트워크 상태에 따라 분석 실패 또는 서비스 일시 중단 가능

### 4. 🔊 TTS 기능 오류

- 특히 인사이트에 텍스트 음성 변환(TTS) 적용 시, 에러 빈도 높음

### 5. 🧪 구글 무료 API 사용 한계

- 무료 API 사용으로 인한 처리 안정성 저하 및 품질 제약
- 향후 유료 API 전환 검토 필요
